# B 사이트 구조 가이드 — 토닥이 이용 전 확인 가이드 (정보형 클러스터)

> **A/B 역할 분담:**
> - A 사이트: `토닥이` 대표 랜딩. 감성 + 정의, 단일 페이지. (`site-a-landing-copy.md`)
> - B 사이트: 세부 의도(뜻·가격·후기·프로필·지역·결제) 공략. 정보 + 판단 기준, 다중 페이지.
>
> 전체 페이지 작성 원칙(정의문 규칙, 톤 배합비, AI 개요 grounding 규칙)은
> `site-structure-and-content-guide.md`를 따른다.

## ⚠️ 착수 전 확정 필요: B의 정체성 (검토 노트)

이 설계안은 "제3자형 확인 가이드"의 문법으로 쓰여 있으나, B가 실제 서비스
운영자 소유라면 중립 가이드로 위장해서는 안 된다. **권장 해법: 운영 주체를
공개한 서비스 사이트가 "확인 가이드"의 문법으로 말하는 구조.**

1. `/price/`에는 실제 가격표(HTML 표)를 넣고, "확인 기준" 콘텐츠는 그 표의
   해설로 붙인다. 실제 숫자 없는 "확인 기준"만으로는 `토닥이 가격` 쿼리의
   AI 개요 grounding을 가져올 수 없다 (경쟁사 인용 원인이 실제 A/B/C 가격표였음).
2. `/area/{city}/`의 "실제 가능 권역·시간대"는 업체만 말할 수 있는 정보다.
   서비스 사이트임을 전제로 작성한다.
3. 운영 주체·연락처를 푸터와 `/payment-safety/`에 명시한다 (E-E-A-T 투명성).

또한 B 홈의 "이용 전 확인 가이드" 포지션은 todacktop.com, todacke.com이
이미 점유한 앵글이다. 단, 둘 다 단일 페이지이므로 B의 차별화는 포지션
이름이 아니라 **클러스터 깊이**에서 나온다. 1차 오픈 페이지 각각이 해당
의도의 최고 문서여야 한다.

---

## 1. 핵심 포지션

> 토닥이 이용 전 확인 가이드
> = 토닥이 뜻, 가격, 코스, 후기, 프로필, 가능 지역, 결제 기준을
>   예약 전 확인하는 여성전용마사지 안내 사이트

## 2. 사이트 구조

```
/
├─ /meaning/          토닥이 뜻 · ㅌㄷㅇ 뜻
├─ /price/            가격 · 코스 (실제 가격표 + 확인 기준)
├─ /reviews/          후기 확인법
├─ /profile/          관리사 프로필 확인 기준
├─ /guide/            예약 전 이용 순서
├─ /payment-safety/   결제 · 예약금 · 후불 · 안전
├─ /faq/              자주 묻는 질문
├─ /area/             지역 허브
│  ├─ /area/suwon/
│  ├─ /area/incheon/
│  ├─ /area/busan/
│  └─ /area/{city}/   실서비스 가능 지역만
└─ /blog/             인접 정보성 쿼리 (스웨디시란, 홈타이 차이 등)
```

## 3. 페이지별 역할

### `/` (허브)
- **Title:** `토닥이 이용 전 확인 가이드 | 뜻·가격·후기·지역`
- **H1:** `토닥이 이용 전 확인 가이드`
- **역할:** B 전체 허브. `토닥이` 단독이 아니라 "이용 전 확인" 의도를 먹는다.
- **첫 문단:** "토닥이를 이용하기 전에는 뜻, 가격, 후기, 프로필, 가능 지역,
  결제 기준을 나눠 확인하는 것이 좋습니다. 이 사이트는 여성전용마사지
  이용자가 예약 전에 확인해야 할 기준을 페이지별로 정리합니다."

### `/meaning/`
- **Title:** `토닥이 뜻 | ㅌㄷㅇ 뜻과 여성전용마사지 의미`
- **H1:** `토닥이 뜻`
- **구성:** 말의 유래 → 위로의 의미 → 여성전용마사지 용어 → 홈타이와의 관계 → FAQ

### `/price/`
- **Title:** `토닥이 가격과 코스 확인 기준`
- **H1:** `토닥이 가격과 코스`
- **구성:** 기본 코스 구분, 시간별 차이, 지역별 변동, 예약 전 확인할 비용,
  추가비·예약금 주의
- **주의:** 실제 가격표가 있으면 HTML 표로 게시하고 확인 기준을 해설로 붙인다.
  실제 가격표가 없으면 숫자를 만들어내지 말고 확인 기준 중심으로만 작성한다.

### `/reviews/`
- **Title:** `토닥이 후기 확인법 | 실제 후기에서 봐야 할 기준`
- **H1:** `토닥이 후기 확인 기준`
- **구성:** 좋은 후기의 조건, 과장 후기 구분, 지역·응대·코스·재이용 의사 확인법

### `/profile/`
- **Title:** `토닥이 프로필 확인 기준 | 관리사 선택 전 체크사항`
- **H1:** `토닥이 프로필 확인 기준`
- **구성:** 프로필에서 볼 정보, 가능 시간, 지역, 안내 방식, 과장 표현 주의
- **주의:** 외모 중심 표현 금지, 선택 기준 중심으로

### `/guide/`
- **Title:** `토닥이 예약 전 이용 순서`
- **H1:** `토닥이 이용 순서`
- **구성:** 지역 확인 → 코스 확인 → 프로필 확인 → 후기 확인 → 결제 기준 확인 → 상담

### `/payment-safety/`
- **Title:** `토닥이 결제·예약금·후불 확인 기준`
- **H1:** `토닥이 결제와 예약 전 주의사항`
- **구성:** 예약금, 후불, 환불, 사칭, 과한 선입금 요구, 상담 중단 기준
- **추가:** 운영 주체·연락처 명시 (신뢰 앵커 페이지)

### `/area/` (지역 허브)
- **Title:** `지역별 토닥이 안내 | 수원·인천·부산 여성전용마사지`
- **H1:** `지역별 토닥이 안내`
- **구성:** 주요 지역 목록, 지역별 확인 기준, 가격/후기/프로필 페이지 내부링크

### `/area/{city}/` (예: 수원)
- **Title:** `수원 토닥이 | 수원 여성전용마사지 이용 전 확인 기준`
- **H1:** `수원 토닥이`
- **구성:** 수원 이용 가능 여부, 인계동/광교/영통 등 실제 가능 권역,
  시간대, 코스 확인 기준, 지역 FAQ
- **주의:** 도시명만 바꾼 복제 페이지 금지. 실서비스 가능 지역만 index.

## 4. 오픈 우선순위

| 차수 | 페이지 |
|---|---|
| 1차 | `/`, `/meaning/`, `/price/`, `/reviews/`, `/area/`, `/area/suwon/`, `/area/incheon/` |
| 2차 | `/profile/`, `/guide/`, `/payment-safety/`, `/faq/` |
| 3차 | 실서비스 가능 지역 페이지만 순차 추가 |

(1차의 지역 페이지도 실서비스 검증이 전제. 검증 안 된 지역은 차수와 무관하게 만들지 않는다.)

## 5. 톤앤매너

- 감성 20 : 정보 80
- "예약하세요"보다 "확인하세요"
- 금지: "1위", "훈남", "연예인급", "최대규모"
- 판단 기준 중심 어휘: 가격, 코스, 후기, 프로필, 지역, 결제 기준
- 의료 효과 표현(치료, 림프 개선, 숙면 유도 등)은 근거 없으면 사용 금지

## 6. A/B 카니발리제이션 방지 규칙

| 키워드 | 전담 페이지 |
|---|---|
| `토닥이` (대표 정의) | A 사이트 |
| `토닥이 이용 전 확인` | B `/` |
| `토닥이 뜻` | B `/meaning/` |
| `토닥이 가격` | B `/price/` |
| `토닥이 후기` | B `/reviews/` |
| `수원 토닥이` | B `/area/suwon/` |

- B 홈 title/H1을 `토닥이` 단독으로 만들지 않는다.
- 지역 페이지에서 공통 정의문을 길게 반복하지 않는다.
- 가격표는 `/price/`에만, 후기 판단 기준은 `/reviews/`에만 둔다.
- 약한 지역 페이지는 `noindex, follow`.

## 7. 내부링크 흐름

```
/            → /meaning/, /price/, /reviews/, /area/
/meaning/    → /price/, /guide/
/price/      → /guide/, /payment-safety/
/reviews/    → /profile/, /area/
/profile/    → /reviews/, /guide/
/area/       → 각 지역 페이지
지역 페이지  → /price/, /reviews/, /guide/
```

## 9. SERP 근거

현재 `토닥이` SERP가 이 구조를 지지한다: todak-2.com(업체·후기·프로필
커뮤니티형), todaqi.com(정의·진행 방식·확인 기준), App Store/Google Play
토닥이 앱(주변샵·후기·가격/할인·관리사 정보 강조), todacktop.com(가이드형
단일 페이지). B가 공략할 실전 의도는 "뜻" 하나가 아니라
**가격 · 후기 · 프로필 · 지역 · 예약 전 확인**의 묶음이다.
