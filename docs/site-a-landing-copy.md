# 토닥이.com 단일페이지 랜딩 최종 문안 (v3 — FAB 상담형 확정본)

> **역할:** 토닥이.com은 하위 페이지를 정리하고 **단일페이지 랜딩 + FAB(카톡
> 상담)** 구조로 운영한다. `토닥이`의 이중 의미(위로의 말 + 여성전용마사지)를
> 정의하고, 상담 전 판단 기준과 즉시 상담 동선까지 한 페이지에서 완결하는
> 상담형 랜딩이다. B 사이트·외부 연결 전제는 문안에서 완전히 제거되었다.

## 게시 전 체크

1. **사실 검증:** `서울, 수원, 인천, 부산` 등 지역 문구는 실제 운영 사실과
   일치할 때만 게시한다.
2. **본문 중복 게시 금지:** 문안 블록이 페이지에 두 번 붙지 않았는지 확인.
3. **하위 URL 정리:** 색인된 하위 페이지는 **홈으로 301** (404/410보다
   색인·링크 자산 승계에 유리). sitemap도 단일 URL로 갱신.
4. **/about/ 동기화:** "예약 중개 안 함" 류 문구 제거 — FAB 상담형과 모순.
5. **FAQ 7문항에 `FAQPage` 구조화 데이터 적용.**
6. **A/B 분리 운영 체크** (하단 섹션) 이행 후 게시.
7. 라이브 페이지에는 아래 "문안 전문" 블록 내부만 사용한다.
8. 게시 후 GSC에서 홈 URL 재색인 요청 + 구 title 캐시 갱신 확인.

## v3 개정 내역 (v2 대비)

1. **승부 문장 채택** — Hero 2문단이 위로+정의+판단기준 3축 통합 정의문으로 교체됨.
2. **B/다중페이지 전제 완전 제거** — "이용 안내 페이지" 등 외부 연결 표현 없음.
   상담 동선은 전부 FAB/CTA로 수렴.
3. **신규 섹션 "처음 상담할 때 이렇게 물어보세요"** — 질문 리스트가 대화형
   쿼리("토닥이 상담 뭐 물어봐야") grounding + FAB 진입 브릿지를 겸한다.
   현재 SERP에 이 형식의 문서가 없어 정보 이득이 실재하는 섹션.
4. **FAQ 7번 신설** ("상담만 해도 되나요? → 네.") — 상담 진입 마찰 제거.
5. **확인 기준에 "불편한 상황에서 중단할 수 있는지" 추가** — 안전 신호.
6. **뜻 섹션에 자기 범위 선언** ("이 페이지에서 말하는 토닥이는~") —
   페이지 스코프 명시로 다의어 해소 강화.
7. **CTA 어휘 통일** — "오늘 가능 여부 확인하기 / 카톡 상담하기" (FAB 문구와 일치).

## 구현 시 다듬기 후보 (선택, 비차단)

- "확인"이 본문 전체에서 30회 이상 등장한다. 의미가 같은 자리 일부를
  "물어보기", "알아보기", "살펴보기"로 치환하면 기계적 인상이 줄어든다.
  단, Hero 정의문·FAQ 첫 문장·H2 제목의 "확인"은 유지(추출 단위).

## A/B 분리 운영 체크 (연관성 없음 전략의 성립 조건)

- [ ] A의 FAB 카카오 채널을 B와 **별도 채널**로 개설 (같은 카카오 ID·QR이면 전략이 깨짐)
- [ ] 전화번호·사업자 표기·footer 문구가 B와 겹치지 않는지 확인
- [ ] 같은 GA/애널리틱스 계정, 같은 서버·템플릿 재사용 최소화
- [ ] A는 `토닥이` 본 키워드 전담, B 홈은 `토닥이` 단독 타깃 금지

**리스크 고지:** 채널을 분리해도 Google이 운영 주체를 연관 지을 가능성은
남는다(결제·호스팅·콘텐츠 패턴). 동일 운영자의 복수 서비스 사이트가 같은
키워드 공간을 점유하는 구조는 발각 시 도어웨이/사이트 평판 남용으로 두
사이트가 함께 하락할 수 있다. 유일한 실질 방어선은 은폐가 아니라
콘텐츠·역할 차별화(A=대표 정의+상담 완결, B=가격·프로필·지역 운영)다.
