# 토닥이.com 단일페이지 랜딩 최종 문안 (v2 — FAB 상담형)

> **역할 (2026-07 피벗):** 토닥이.com은 하위 페이지를 정리하고 **단일페이지
> 랜딩 + FAB(카톡 상담)** 구조로 재편한다. `토닥이`의 이중 의미(위로의 말 +
> 여성전용마사지)를 정의하고, 상담 전 판단 기준까지 한 페이지에서 제공하는
> 상담형 랜딩이다.
>
> ⚠️ **이 피벗은 `entity-separation-plan.md`의 "A = 편집형 정보 엔티티(상담
> CTA 금지)" 설계를 대체한다.** FAB 상담이 붙는 순간 A는 정보 사이트가 아니라
> 서비스 랜딩이므로, /about/의 "예약 중개를 하지 않습니다" 류 문구는 함께
> 제거/수정해야 한다. 정보 사이트 선언 + 상담 FAB 조합이 최악의 모순이다.

## 게시 전 체크

1. **사실 검증:** `서울, 수원, 인천, 부산` 등 지역 문구는 실제 운영 사실과
   일치할 때만 게시한다.
2. **본문 중복 게시 금지:** 문안 블록이 페이지에 두 번 붙지 않았는지 확인
   (기존 페이지에서 중복 삽입이 관측됨).
3. **하위 URL 정리:** 색인된 하위 페이지는 일괄 삭제(404/410)보다
   **홈으로 301**이 안전하다 (기존 색인·링크 자산 승계). 잔존시킬 페이지가
   있으면 canonical을 홈으로.
4. **/about/ 동기화:** "예약 중개 안 함" 문구 제거, 운영 주체·상담 채널 명시.
5. **FAQ에 `FAQPage` 구조화 데이터 적용.**
6. 라이브 페이지에는 아래 "문안 전문" 블록 내부만 사용한다.

## v2 개정 내역

1. **"이용 안내 페이지" 표현 전부 제거** — 단일페이지 구조와 모순.
   Hero는 "상담 전 먼저 확인할 수 있습니다", 코스·가격 섹션은
   "화면의 상담 버튼으로 바로 물어볼 수 있습니다"(FAB 유도)로 교체.
2. **인간화 리라이팅** — "확인", "기준", "~좋습니다" 반복을 줄이고
   실제 이용 장면(야근 후 귀가, 추가 비용에 놀라는 상황)을 추가.
   단, **정의문과 FAQ는 단정형 그대로 유지** (AI 개요 추출용).
   목표 배합: AI 개요용 단정 문장 30% / 자연스러운 설명 50% / 전환 문장 20%.
3. **상담 CTA 복원** — FAB 상담형 랜딩 전제. v1(정보형 CTA)은 폐기.
4. **OG Description에서 "후기" 제거** — 페이지에 후기 모음이 없으므로
   기대 불일치 방지.

### A/B 분리 운영 체크 (연관성 없음 전략의 성립 조건)

A와 B를 연결하지 않는 전략을 택했다면, 링크만 없애는 것으로는 부족하다:

- [ ] A의 FAB 카카오 채널을 B와 **별도 채널**로 개설 (같은 카카오 ID·QR이면 전략이 깨짐)
- [ ] 전화번호·사업자 표기·footer 문구가 B와 겹치지 않는지 확인
- [ ] 같은 GA/애널리틱스 계정, 같은 서버·템플릿 재사용 최소화
- [ ] A는 `토닥이` 본 키워드 전담, B 홈은 `토닥이` 단독 타깃 금지 (기존 원칙 유지)

**리스크 고지:** 채널을 분리해도 Google이 운영 주체를 연관 지을 가능성은
남는다(결제·호스팅·콘텐츠 패턴). 동일 운영자의 복수 서비스 사이트가 같은
키워드 공간을 점유하는 구조는 발각 시 도어웨이/사이트 평판 남용으로 두
사이트가 함께 하락할 수 있는 구조임을 전제하고, 두 사이트의 콘텐츠·역할
차별화(A=대표 정의+상담, B=가격·프로필·지역 운영)를 실질적으로 유지하는
것이 유일한 방어선이다.

축적 신호 추월)에 달려 있어 가장 예측 불확실성이 크다.

- 나쁜 인간화: "오늘도 너무 힘드셨죠? 이제 아무 걱정하지 마세요.
  토닥이가 완벽하게 힐링해드립니다." (과장 + 정보 없음)
- 좋은 인간화: 장면 묘사 + 그 장면에서 필요한 판단 정보를 같은 문단에.
- 정의문·FAQ 답변 첫 문장은 절대 풀어 쓰지 않는다.
