# A 사이트 메인 랜딩 최종 문안

> **역할:** A 사이트는 `토닥이`의 이중 의미(위로의 말 + 여성전용마사지 서비스 용어)를
> 한 페이지에서 해소하는 대표 정의형 랜딩. 가격표 숫자, 지역별 상세 문구, 후기 모음은
> B 사이트(`/price/`, `/reviews/`, `/area/`)의 영역이므로 A에서는 요약과 링크로만 다룬다.

## 게시 전 체크 3가지

1. **사실 검증:** `서울, 수원, 인천, 부산`, `24시간`, `후불/예약금` 관련 문구는
   실제 운영 사실과 일치할 때만 게시한다.
2. **A→B 링크는 2개 이하:** "이용 안내 페이지", "지역별 코스와 가격" 정도의
   문맥 링크만. A는 자기완결 문서로 성립해야 한다.
3. **FAQ에 `FAQPage` 구조화 데이터 적용.**
