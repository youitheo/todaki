# A/B 엔티티 분리 계획 — 토닥이.com × todaqi.com

> **결론:** A(토닥이.com)는 "토닥이 뜻·기준·주의사항을 정리하는 편집형 정보
> 엔티티", B(todaqi.com)는 "가격·프로필·지역·상담을 맡는 운영형 서비스
> 엔티티"로 분리한다. 현재 A에 열려 있는 가격/후기/프로필/지역 페이지가
> B와 충돌하므로 A를 "확인 기준" 중심으로 재편한다.

## ⚠️ 검토 노트 — 착수 전 반드시 처리 (우선순위순)

### 1. A의 상담/카톡/전화 CTA 제거 — 구조적 모순 해소 (최우선)

A는 /about/에서 "예약이나 업체 추천 없이" 정보 사이트임을 표방하는데,
현재 A에 외부 `qr.kakao.com` 링크(카톡 상담 CTA)가 존재한다. 정보
사이트가 카톡/전화 상담 CTA를 달면 "예약 중개 안 함" 선언과 정면
충돌하며, **A 전체가 상담으로 보내는 도어웨이로 평가될 수 있다.**

**A에서 제거할 CTA:**
```
상담 문의하기 / 전화하기 / 카톡문의 / 예약 가능 여부 확인
```

**A에 둘 CTA (전부 내부 또는 정보형):**
```
토닥이 뜻 보기          (→ /meaning/)
이용 전 확인 기준 보기   (→ /faq/ 또는 체크리스트)
정보 정정 요청하기       (→ /correction-request/)
피해·사칭 사례 제보하기  (→ /scam/ 또는 /contact/)
```

B로 가는 연결은 CTA 버튼이 아니라 본문 문맥 링크 1~2회로만:
"실제 지역별 코스와 상담은 토닥이 공식센터에서 확인할 수 있습니다."

`site-a-landing-copy.md`의 확정 문안 CTA("상담 문의하기", "이용 가능 여부
확인하기")도 동일 기준으로 개정 필요.

### 2. 구(舊) 선정적 title의 검색 캐시 잔존 확인 (경정)

라이브 사이트의 현재 title은 `토닥이 | 여성전용 방문마사지 뜻과 확인 기준`
으로 이미 정보형 포지션에 맞게 교체되어 있다 (2026-07 확인).
다만 일부 검색 스냅샷/캐시에는 과거 title("남친보다 낫다? ~ 시크릿 홈케어")이
잔존하는 것이 관측되었다. 후속 조치:

- GSC에서 홈 URL 색인 재요청 (URL 검사 → 재색인)
- `site:` 검색으로 SERP title 갱신 여부 주기 확인
- 과거 선정적 카피가 남아 있는 페이지/OG 태그가 더 있는지 전수 점검
  (성인 카테고리 분류 리스크는 캐시가 갱신되어야 해소된다)

### 3. "중립 정보 사이트" 주장과 실제 운영 관계의 정합성

A가 "업체 추천은 하지 않습니다"라고 선언하면서 외부 링크가 B 하나뿐이면,
사실상 단일 업체 추천이며 중립성 주장이 스스로 무너진다. 관계는 숨기기보다
공개하되, **sameAs로 묶지는 않는다** — sameAs는 "동일 엔티티" 선언이라
A 정보 사이트와 B 서비스 사이트를 하나로 합쳐버린다.

**A /about/ 기본 문구 (관계 비공개 시):**
> 토닥이.com은 토닥이 관련 뜻과 이용 전 확인 기준을 정리하는 정보형
> 사이트입니다. 특정 예약을 직접 처리하지 않으며, 실제 상담·예약·가격
> 확인은 별도 운영 채널에서 진행됩니다. 본 사이트는 이용자가 예약 전
> 스스로 판단할 수 있도록 기준 정보를 제공합니다.

**관계 공개 시 추가 문구:**
> 토닥이.com과 todaqi.com은 같은 주제군을 다루지만 역할을 분리해
> 운영됩니다. 토닥이.com은 정보·기준 안내를, todaqi.com은 실제
> 가격·프로필·지역·상담 안내를 담당합니다.

포지션은 "독립 정보 사이트"가 아니라 **"역할 분리 정보 사이트"**로.
관계 은폐가 목적이 되는 순간 도어웨이/위성 사이트 패턴으로 평가될
리스크가 생긴다.

### 4. "공식센터" 명칭

상표 등록이 없어도 사용은 가능하나, "공식"이 무엇을 의미하는지 설명이
필요하다(경쟁사도 "공식" 남발 중이라 근거 명시가 오히려 차별화가 된다).

**B /about/ 또는 홈 하단에 추가할 문구:**
> 여기서 말하는 공식센터는 todaqi.com에서 직접 운영하는
> 가격·코스·프로필·지역 상담 안내 채널을 뜻합니다.

## 1. 엔티티 정의

### A — 토닥이.com
- **유형:** 토닥이 용어·이용 기준 정보 사이트 (편집형)
- **핵심 정의문:** "토닥이.com은 토닥이의 뜻, 여성전용 방문마사지 이용 전
  확인 기준, 후기·결제·사칭·법적 주의사항을 정리하는 정보 사이트입니다.
  특정 업체의 예약을 직접 처리하지 않으며, 가격·후기·결제·사칭·지역 확인
  시 주의할 기준을 안내합니다." (검토 노트 3 반영판)
- **전담 주제:** 토닥이 뜻, ㅌㄷㅇ 뜻, 여성전용마사지와의 관계, 후기 구분법,
  예약금·후불 확인 기준, 사칭·피해 예방, 건전한 서비스 범위, 첫 이용 체크리스트

### B — todaqi.com (토닥이 공식센터)
- **유형:** 여성전용 남성관리사 출장마사지 안내·상담 사이트 (운영형)
- **핵심 정의문:** "토닥이 공식센터는 여성 고객이 예약 전 가격, B/C코스,
  남성관리사 프로필, 후기, 결제 방식, 가능 지역을 확인하고 상담할 수 있는
  여성전용 남성관리사 출장마사지 안내 사이트입니다."
- **전담 주제:** 토닥이 가격, B/C코스, 관리사 프로필, 지역별 토닥이
  (수원/인천/강남 등), 카톡 상담, 후기, 결제·예약금, 예약 전 문의

## 2. A 사이트 재편

### 유지/강화
```
/  /meaning/  /legal/  /scam/  /payment/  /naesang/  /glossary/
/faq/  /about/  /editorial-policy/  /correction-request/  /contact/
```

### 축소 또는 noindex 검토
```
/price/  /course/  /profile/  /reviews/  /regions/*  /women-massage/  /c-course/
```

**처리 원칙:** 삭제가 아니라 역할 전환. A의 /price/, /profile/, /reviews/를
유지하려면 "예약·상담용 상세 정보"가 아니라 **"확인 기준" 페이지로만**
남긴다. 실제 가격표, 지역별 예약, 관리사 선택, 후기 모음은 B 전담.
**A의 지역 페이지(/regions/*)는 noindex** — 지역 조합 쿼리는 B가 전담한다.

## 3. B 사이트 구조

```
/                       공식센터 허브
/price/                 토닥이 가격, B코스, C코스
/profile/               남성관리사 프로필
/local/                 지역별 토닥이 허브
/local/suwon/ 등        지역 조합 페이지 (실서비스 지역만)
/reviews/               후기 대표 허브 — 신규 생성 (흩어진 후기 포스트를 내부링크로 묶기)
/todaki-safe-payment/   결제·예약금·후불 기준
/todaki-first-time/     처음 이용 가이드
/kakao/                 카톡 상담 흐름
/faq/                   예약 전 질문 정리
/contact/               상담 연결
```

### B 정리 작업
- **/reviews/ 대표 허브 신규 생성** — 현재 후기 글이 포스트로 흩어져 있어
  `토닥이 후기` 쿼리의 대표 URL이 없다.
- **/todaki-meaning/은 축소** — A /meaning/과 겹치지 않게 "공식센터에서
  쓰는 토닥이 기준" 수준으로만.
- **블로그 의료성 글(효과, 통증, 임신, 림프, 두통 등) 정리 또는 noindex** —
  YMYL 신호를 키우고 엔티티를 흐린다. B는 가격·프로필·지역·후기·결제·상담에 집중.

## 4. A/B 링크 규칙

| 방향 | 허용 | 위치 |
|---|---|---|
| A → B | 1~2회 | A 홈 또는 A 가격 기준 페이지 본문: "실제 지역별 코스와 상담은 토닥이 공식센터에서 확인할 수 있습니다." |
| B → A | 1회 | B /todaki-meaning/ 또는 FAQ: "용어의 뜻과 이용 전 기준은 토닥이.com 기준 안내에서 볼 수 있습니다." |

**금지:**
- A 전 페이지 하단 B 상담 CTA 반복
- B 전 페이지 A 뜻 링크 반복
- cross-domain canonical
- (sameAs는 별개 엔티티 운영 원칙상 미사용 — 단 검토 노트 3의 관계 공개와 병행)

> 정리하는 정보 사이트입니다. 특정 업체의 예약을 직접 처리하지 않으며,

## 7. GSC 모니터링 기준

**A가 정상:** `토닥이 뜻`, `ㅌㄷㅇ 뜻`, `토닥이 사칭`, `토닥이 예약금`,
`토닥이 후기 구분`, `토닥이 합법`

**B가 정상:** `토닥이`, `토닥이 가격`, `토닥이 프로필`, `토닥이 후기`,
`수원 토닥이`, `인천 토닥이`, `토닥이 카톡`, `토닥이 B코스`

**문제 신호:**
- A /price/가 `토닥이 가격`에서 B /price/와 경쟁
- A /regions/suwon/이 B /local/suwon/과 경쟁
- B /todaki-meaning/이 A /meaning/과 경쟁
- A가 상담 CTA만 보내는 도어웨이처럼 보임
- B 블로그 의료성 글이 토닥이 엔티티 페이지보다 더 많이 노출

(운영 팁: GSC 실적 보고서에서 쿼리별 노출 URL을 주기 확인 —
같은 쿼리에 A/B URL이 번갈아 노출되면 카니발리제이션 진행 신호다.)

## 8. 실행 우선순위 (확정판)

1. **A의 전화/카톡/상담 CTA 제거** — 정보 정정·제보용 CTA로 교체 (검토 노트 1)
2. **A /about/ 문구 정리** — "독립 정보 사이트"가 아니라 "역할 분리 정보 사이트"로 (검토 노트 3)
3. **A /regions/* noindex 검토**
4. **A /price/, /profile/, /reviews/는 "확인 기준" 페이지로만 유지**
5. **B /reviews/ 대표 허브 생성** + 후기 포스트 내부링크 정리
6. **B "공식센터" 근거 문구 추가** (검토 노트 4)
7. **B 의료성 블로그 글 noindex/정리 검토**
8. **GSC에서 A/B 쿼리 충돌 모니터링** + 구 title 캐시 갱신 확인 (검토 노트 2)
