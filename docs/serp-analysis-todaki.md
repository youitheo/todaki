## 2. 상위 1~10위에서 안 다루거나 없는 구조 (콘텐츠 갭)

### A. 완전히 비어 있는 구조
1. **뜻/유래 정의 콘텐츠** — "토닥이 뜻" 계열 콘텐츠는 nkbada, maddago 등 하위권에만 존재. 상위 10위 중 용어 정의·유래를 정면으로 다루는 페이지 없음. 5위에 의료기기가 섞여 있을 만큼 의미가 혼재되어 정의형(informational) 콘텐츠 기회가 큼.
2. **사기·선입금 피해 예방 콘텐츠** — "토닥이 사기/먹튀/선입금 주의" 검색 시 관련 결과가 사실상 전무. 예약금을 요구하는 구조가 존재하는 시장인데 피해 유형·확인 체크리스트·대처법을 다루는 곳이 없음 → 신뢰(E-E-A-T) 확보에 가장 큰 갭.
3. **비교 구조** — 토닥이 vs 스웨디시 vs 1인샵 vs 홈타이, 앱 vs 업체 직접예약 비교표 없음 (gachinolja가 종류만 나열).
4. **가격 실데이터** — 전부 동일한 표준 가격표만 반복. 지역별·심야 출장비·연장 요금 차이, 연도별 변동 등 실측 데이터 표 없음 (todacke가 "연도별 정리" 시도한 정도).
5. **법·위생·자격 안내** — 합법 여부, 관리사 자격/교육, 위생 기준을 다루는 페이지 없음.
6. **구조화 데이터 활용** — FAQPage, Review/AggregateRating, LocalBusiness 스키마 등 리치결과 대응 흔적이 상위권에 없음.

### B. 한두 곳만 다루는 약한 구조 (차별화 여지)
7. **FAQ 페이지** — yeodae.com 한 곳만 보유.
8. **첫 이용자 스텝별 가이드** — todacktop이 꿀팁(추천 시간대, 준비물 불필요) 단편만. 문의→초이스→도착(30~40분)→코스 결정→후불 결제까지 타임라인/체크리스트형 콘텐츠 없음.
9. **관리사 되는 법/구인** — todaqi.com만 recruit 페이지 보유. "토닥이 알바/구인" 수요 미공략.
10. **집계형 후기/랭킹** — todak-2만 커뮤니티·랭킹 구조. 나머지는 자사 게시판 후기라 신뢰도 낮음. 평점 통계·업체별 비교 후기 구조 없음.
11. **세그먼트별 콘텐츠** — 커플/임산부/의료 마사지가 코스명으로만 언급되고 전용 페이지 없음.
12. **지역 상세 페이지의 깊이** — todaqi·gachinolja가 지역 페이지를 갖고 있으나 대부분 얇은 복제형. 지역별 시세·업체 수·후기 등 고유 데이터 없음.
