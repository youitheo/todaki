# 토닥이 키워드 사이트 구축 가이드
## 사이트 구조 · 페이지별 콘텐츠 방향 · 톤앤매너

> 이 가이드는 `토닥이`(여성전용마사지) 키워드에 대한 Google AI 개요 인용 분석과
> 한국어 의미 공간 분석을 바탕으로 작성되었다.
> 핵심 전제 두 가지:
> 1. **AI 개요 인용은 "좋은 페이지 선발"이 아니라 "생성된 문장을 지지하는 문서 매칭(grounding)"이다.**
>    → 모든 핵심 페이지는 AI가 그대로 가져다 쓸 수 있는 완결된 문장을 공급해야 한다.
> 2. **`토닥이`는 사전에 없는 신조 명사라 의미가 웹 문서 분포로 결정된다.**
>    → 의미 공간은 선점 가능하며, "모호성을 가장 완결적으로 해소하는 단일 문서" 자리는 아직 비어 있다.

---

## 0. 전략의 한 문장

> **토닥이 = 지친 여성이 몸과 마음을 조용히 쉬기 위해 찾는 여성전용마사지.**

이 정의가 사이트 전체의 뼈대다. 모든 페이지의 첫 문단은 이 정의의 변주이고,
모든 톤앤매너 결정은 이 정의의 앞부분(감성)과 뒷부분(정보) 사이의 배합비 조절이다.

---

## 1. 사이트 전체 구조 (사이트맵)

```
/                           메인 — 정의 + 전체 개요 (허브)
├── /meaning/               토닥이 뜻 — 사전형 정의 페이지 (AI 개요 핵심 무기)
├── /price/                 코스 및 가격 — 거래 정보의 표준 문서
├── /guide/                 이용 방법 · 예약 절차
├── /manager/               관리사 소개 · 검증 기준
├── /trust/                 안전 · 신뢰 · 운영 정책
├── /faq/                   자주 묻는 질문 (FAQPage 스키마)
├── /area/                  지역 안내 허브
│   ├── /area/seoul/        서울 (필요시 강남·홍대 등 하위)
│   ├── /area/suwon/        수원
│   ├── /area/incheon/      인천
│   └── /area/busan/        부산
└── /blog/                  정보 콘텐츠 허브
    ├── 스웨디시·아로마 등 관리 방식 설명 글
    ├── 홈타이/출장 마사지 이용 팁
    └── 휴식·셀프케어 감성 칼럼 (링크 자석 역할)
```

### 구조 설계 원칙

| 원칙 | 이유 |
|---|---|
| 깊이 최대 2단계 | 크롤링 효율 + 모든 핵심 페이지가 메인에서 1클릭 |
| 지역 페이지는 허브(/area/) 아래로 격리 | 도어웨이 판정 리스크를 구조적으로 낮추고, 지역 페이지 품질 기준을 별도 관리 |
| 가격은 독립 페이지 | AI 개요의 "코스와 가격" grounding 수요를 단일 URL로 흡수. 경쟁사가 인용된 이유가 정확히 이것 |
| /meaning/ 독립 운영 | `토닥이 뜻`, `ㅌㄷㅇ 뜻` 쿼리 생태계가 이미 검증된 인용 소재 포맷. 사전형 문서 자리가 비어 있음 |
| 블로그는 상업 페이지와 분리 | 정보성 콘텐츠의 신뢰도가 상업 페이지로 오염되지 않게 하고, 내부링크로만 연결 |

### 내부 링크 규칙

- 메인 → 전 핵심 페이지 (본문 문맥 링크, 푸터 나열 아님)
- /meaning/ → 메인, /price/ ("서비스와 가격이 궁금하다면" 문맥 링크)
- 지역 페이지 → /price/, /guide/ (지역 페이지에 가격표 복제 금지, 링크로 위임)
- 블로그 글 → 관련 핵심 페이지 1~2개만 (글마다 상업 링크 도배 금지)
- 앵커 텍스트는 자연 문장형: ~~"수원토닥이 바로가기"~~ → "수원 지역 이용 안내"

## 2. 페이지별 상세 가이드

각 페이지는 다음 5요소로 정의한다: **목적 / 타깃 쿼리 / 메타 패턴 / 구조와 첫 문단 / 톤 배합비**.
톤 배합비는 `감성 : 정보` 비율이다.

---

### 2-1. 메인페이지 `/`

- **목적:** 엔티티 정의의 원본 문서. AI 개요가 "토닥이는 무엇인가"를 인용할 때의 1순위 소스.
- **타깃 쿼리:** `토닥이`, `여성전용마사지`
- **톤 배합비:** 감성 40 : 정보 60

**Title:** `토닥이 | 지친 하루를 쉬어가는 여성전용마사지`
**Meta description:** `토닥이는 지친 하루 끝에 몸과 마음을 조용히 쉬고 싶은 여성을 위한 여성전용마사지 서비스입니다. 서울·수원·인천·부산, 24시간 상담, 코스와 가격을 투명하게 안내합니다.`

**구조:**

```
H1: 토닥이 — 지친 하루 끝, 여성만을 위한 여성전용마사지
  [첫 문단 = 3문장 정의 블록, 아래 참조]
H2: 토닥이란? (여성전용마사지 · 홈타이 서비스 안내)
H2: 이용 가능 지역 — 서울 · 수원 · 인천 · 부산
H2: 코스 및 가격 안내  (요약 3줄 + /price/ 링크)
H2: 이용 방법과 예약 절차  (요약 + /guide/ 링크)
H2: 안전과 신뢰  (요약 + /trust/ 링크)
H2: 자주 묻는 질문  (대표 3개 + /faq/ 링크)
```

**첫 문단 (고정 원문 — 사이트의 정의 원본):**

> 토닥이는 지친 하루 끝에 몸과 마음을 조용히 쉬고 싶은 여성을 위한
> 여성전용마사지 · 홈타이 서비스입니다. 서울, 수원, 인천, 부산 등
> 전국 주요 지역에서 24시간 이용하실 수 있으며, 원하는 코스와
> 가격을 확인한 뒤 취향에 맞는 관리사를 직접 선택해 예약할 수 있습니다.

이 세 문장이 AI 개요의 3대 grounding 수요(정의 / 지역·시간 / 코스·가격·예약)를
한 문장씩 충족한다. **이 문단은 리라이팅 금지, 전 페이지에서 이 표현과 일관성 유지.**

**콘텐츠 방향:**
- 첫 화면(above the fold)에 H1 + 정의 블록 + 상담 CTA 하나만. 슬라이드 배너·팝업 금지.
- 각 H2 섹션은 "요약 + 상세 페이지 링크" 구조. 메인에서 모든 걸 말하려 하지 않는다.
- "1위", "NO.1" 같은 검증 불가 주장 대신 검증 가능한 사실(운영 시간, 지역, 정책)만.

### 2-2. 토닥이 뜻 페이지 `/meaning/`

- **목적:** `토닥이`의 의미 공백을 선점하는 **사전형 문서**. 경쟁사 정의 글은 전부
  홍보에 정의를 곁들인 수준 — 진짜 사전 구조를 갖춘 문서가 나타나면
  AI 개요의 정의 grounding 소스로 교체될 여지가 크다. 이 사이트의 비대칭 무기.
- **타깃 쿼리:** `토닥이 뜻`, `ㅌㄷㅇ 뜻`, `토닥이 의미`, `토닥이 마사지 뜻`
- **톤 배합비:** 감성 10 : 정보 90 (전 페이지 중 가장 건조하게)

**Title:** `토닥이 뜻 — 단어의 유래부터 여성전용마사지 용어까지`

**구조 (위키낱말사전식):**

```
H1: 토닥이 뜻, 정확하게 정리합니다
H2: 어원 — '토닥이다'에서 온 말
  → 의성어 어근 '토닥' + 접미사 '-이', 사전에는 동사 '토닥이다'만 등재
H2: 일반적인 의미 — 위로하고 다독여 주는 존재
H2: 마사지 업계에서의 의미 — 여성전용마사지 서비스의 통칭
  → "마사지 업계에서 토닥이는 여성 고객을 대상으로 하는
     여성전용마사지 · 홈타이 서비스를 가리키는 말입니다." (copula 정의문)
H2: ㅌㄷㅇ 등 변형 표기
H2: 토닥이 서비스는 어떻게 이용하나요?  (메인·가격 페이지 링크, 이 섹션만 상업)
```

**콘텐츠 방향:**
- 각 H2 바로 아래 첫 문장을 완결된 정의문으로. AI가 발췌하는 단위는 "H2 + 직후 1~2문장"이다.
- 어원 설명은 사실만 간결히(위키낱말사전 참조 표기 가능). 지어내지 않는다.
- 상업적 유도는 마지막 H2 하나로 제한. 이 절제가 이 페이지의 경쟁력이다.

### 2-3. 코스 및 가격 페이지 `/price/`

- **목적:** "코스와 가격을 확인하실 수 있습니다"라는 AI 개요 문장의 근거 문서.
  경쟁사(suwontodak2.kr)가 인용된 유일한 이유가 이 정보였다.
- **타깃 쿼리:** `토닥이 가격`, `토닥이 코스`, `여성전용마사지 가격`
- **톤 배합비:** 감성 10 : 정보 90

**Title:** `토닥이 코스 및 가격 안내 | 여성전용마사지`

**구조:**

```
H1: 토닥이 코스 및 가격 안내
  첫 문단: "토닥이의 코스는 A·B·C 세 가지이며, 시간과 가격은 아래 표와 같습니다.
           모든 지역에서 동일한 기준이 적용됩니다." (표를 예고하는 정의문)
H2: 코스별 시간과 가격
  → HTML <table> (이미지 절대 금지): 코스명 | 시간 | 가격 | 포함 내용
H2: 코스 선택 가이드 — 어떤 코스가 맞을까요?
  → 상황별 추천 ("처음이라면 A코스", "온전한 휴식이 필요하다면 C코스")
H2: 추가 비용과 결제 안내
  → 출장비, 심야 할증, 결제 수단 — 숨김 없이 전부 명시
H2: 가격 관련 자주 묻는 질문
```

**콘텐츠 방향:**
- **가격표는 반드시 HTML 텍스트 표.** 이미지 가격표는 AI 개요·검색엔진 양쪽에 존재하지 않는 정보다.
- "추가 비용 없음" 또는 추가 비용 전액 명시 — 가격 투명성 자체가 이 니치에서 희소한 신뢰 신호.
- 갱신일 표기 ("2026년 7월 기준"). 가격 정보의 신선도 신호.

### 2-4. 이용 방법 페이지 `/guide/`

- **목적:** "어떻게 이용하나"라는 절차형 쿼리 응답 + 첫 이용 고객의 불안 해소.
- **타깃 쿼리:** `토닥이 이용방법`, `토닥이 예약`, `홈타이 이용 방법`
- **톤 배합비:** 감성 30 : 정보 70

**구조:**

```
H1: 토닥이 이용 방법 — 상담부터 관리까지
  첫 문단: "토닥이는 상담 → 코스 선택 → 관리사 선택 → 예약 확정 →
           방문 관리의 5단계로 이용하실 수 있습니다."
H2: 1단계 ~ 5단계  (각각 H3 또는 번호 목록, 단계당 2~3문장)
H2: 처음이라 긴장되시나요?  (첫 이용 고객 안심 섹션 — 감성 톤 허용 구간)
H2: 예약 변경과 취소
```

**콘텐츠 방향:**
- 절차는 번호 목록으로 — AI 개요의 절차형 응답은 목록을 그대로 가져간다.
- "처음이라 긴장되시나요?" 섹션이 이 페이지의 감성 쿼터. 여기서만 공감 화법을 충분히 쓴다.
- 취소·변경 정책을 명시하는 것 자체가 신뢰 신호.

### 2-5. 관리사 소개 페이지 `/manager/`

- **목적:** 서비스의 핵심 차별 요소(관리사 선택제)를 설명하고 검증 기준으로 신뢰 구축.
- **타깃 쿼리:** `토닥이 관리사`, `여성전용마사지 관리사`
- **톤 배합비:** 감성 30 : 정보 70

**구조:**

```
H1: 토닥이 관리사 안내 — 선발 기준과 선택 방법
  첫 문단: "토닥이의 관리사는 전원 검증 절차를 거쳐 선발되며,
           고객이 프로필을 보고 직접 선택할 수 있습니다."
H2: 관리사 선발과 검증 기준  (신원 확인, 교육 과정 — 검증 가능한 사실만)
H2: 관리사 선택 방법
H2: 관리 중 지켜지는 원칙  (프라이버시, 응대 기준)
```

**콘텐츠 방향:**
- **외모 서술 최소화.** "훈남 20명 항시대기" 류의 표현은 성인 카테고리 분류 리스크를 높여
  AI 개요 노출 자체를 차단할 수 있다. "검증 절차 · 응대 기준 · 전문성" 프레임으로 서술.
- 선발 기준은 구체적 절차로 (예: "신원 확인 → 면접 → 교육 이수"). 형용사 나열 금지.

### 2-6. 안전 · 신뢰 페이지 `/trust/`

- **목적:** E-E-A-T의 T(신뢰). 이 니치 전체가 신뢰 신호 부재 상태라, 이 페이지 하나가 차별화가 된다.
- **타깃 쿼리:** `토닥이 후기`, `토닥이 안전`, 브랜드 방어 쿼리 전반
- **톤 배합비:** 감성 20 : 정보 80

**구조:**

```
H1: 토닥이의 안전과 신뢰 기준
H2: 운영 주체와 연락처  (상호, 연락 수단, 상담 시간 명시)
H2: 개인정보 보호 원칙  (상담 내역·예약 정보 처리 방침)
H2: 환불 · 취소 정책  (조건과 절차를 표로)
H2: 서비스 범위에 대한 안내  (건전한 관리 서비스임을 명문화)
```

**콘텐츠 방향:**
- "서비스 범위에 대한 안내" 섹션은 방어적 필수 요소: 서비스 성격을 명문화해
  성인 카테고리 오분류를 막는 안전판 역할.
- 전 항목이 검증 가능한 사실이어야 한다. 이 페이지에 수사(修辭)가 들어가는 순간 목적이 죽는다.

### 2-7. FAQ 페이지 `/faq/`

- **목적:** 롱테일 질문 쿼리 흡수 + AI 개요/AI 모드의 Q&A grounding 소스.
- **타깃 쿼리:** `토닥이 ~인가요` 형태의 질문형 쿼리 전반
- **톤 배합비:** 감성 20 : 정보 80

**구성 규칙:**
- 질문은 실제 검색 쿼리 그대로: "토닥이는 어떤 서비스인가요?", "가격은 얼마부터인가요?",
  "당일 예약도 가능한가요?", "처음인데 어떻게 시작하나요?", "관리사는 어떻게 선발되나요?"
- **답변 첫 문장이 완결된 단답**이어야 한다. "네, 당일 예약이 가능합니다. 다만 ~" 구조.
- `FAQPage` 구조화 데이터 적용.
- 문항 10~15개. 다른 페이지 내용의 복제 문항은 만들지 않는다(요약 + 링크로).

### 2-8. 지역 페이지 `/area/{지역}/`

- **목적:** `수원토닥이`, `인천 여성전용마사지` 등 지역+키워드 조합 쿼리 대응.
  AI 개요가 지역 언급 시 인용할 지역별 근거 문서.
- **타깃 쿼리:** `{지역}토닥이`, `{지역} 여성전용마사지`, `{지역} 홈타이`
- **톤 배합비:** 감성 30 : 정보 70

**Title 패턴:** `{지역} 토닥이 | {지역} 여성전용마사지 안내`

**구조 (전 지역 공통 골격):**

```
H1: {지역} 토닥이 — {지역} 여성전용마사지 안내
  첫 문단: "{지역}에서도 토닥이 여성전용마사지를 24시간 이용하실 수 있습니다.
           출장 가능 범위는 {지역 고유 동네 나열}이며, 코스와 가격은
           전 지역 동일합니다."
H2: {지역} 출장 가능 지역  (실제 동·구 단위 — 지역 고유 콘텐츠의 핵심)
H2: {지역} 이용 안내  (해당 지역 소요 시간, 심야 이용 등 지역 고유 정보)
H2: 코스와 가격  (2~3줄 요약 + /price/ 링크. 표 복제 금지)
H2: {지역} 예약 방법
```

**도어웨이 판정을 피하는 3규칙 (가장 중요):**
1. **지역 고유 정보가 본문의 30% 이상** — 출장 범위(동 단위), 지역별 소요 시간,
   해당 지역 고객이 실제로 묻는 질문 등. 지역명만 치환한 복제 페이지는 만들지 않는다.
2. **가격표·정의문 원본을 복제하지 않는다** — 요약 후 원본 페이지로 링크. 중복 콘텐츠 방지.
3. **실제 서비스 가능한 지역만 만든다** — 커버 못 하는 지역 페이지 양산은 스팸 정책 직행.

### 2-9. 블로그 `/blog/`

- **목적:** ① 인접 정보성 쿼리로 엔티티 강화 ② 감성 콘텐츠의 전용 공간
  ③ 자연 링크 획득(링크 자석).
- **톤 배합비:** 글 유형에 따라 가변

**3가지 글 유형과 배합비:**

| 유형 | 예시 주제 | 배합비 | 역할 |
|---|---|---|---|
| 용어·정보형 | "스웨디시란?", "홈타이와 출장마사지 차이" | 감성 10:90 | 인접 쿼리 점유, /meaning/과 함께 사전 포지션 강화 |
| 가이드형 | "여성전용마사지 처음 이용할 때 체크리스트" | 감성 30:70 | 첫 이용 고객 유입, FAQ·guide로 연결 |
| 감성 칼럼형 | "번아웃, 몸부터 쉬어야 하는 이유" | 감성 70:30 | 브랜드 톤 구축, 공유·링크 유도. **상업 링크는 글당 1개 이하** |

- 발행 주기보다 품질: 월 2~4편이라도 각 글이 해당 쿼리의 최고 문서를 목표로.
- 감성 칼럼에서도 첫 문단은 글의 주제를 요약하는 정보 문장으로 시작(두괄식 유지).

## 3. 톤앤매너 시스템

### 3-1. 브랜드 보이스 3원칙

1. **"위로하되, 정의로 말한다"** — 감성 어휘는 반드시 정보 문장의 관형절로 내장한다.
   - ✅ "지친 하루 끝에 몸과 마음을 쉬고 싶은 여성을 위한 여성전용마사지입니다."
   - ❌ "오늘도 수고한 당신에게, 토닥토닥." (단독 감성 문장 — AI가 가져갈 정보가 없음)
2. **"조용한 확신"** — 과장·최상급 대신 검증 가능한 사실을 담담하게.
   - ✅ "24시간 연중무휴로 상담을 받습니다."
   - ❌ "재방문율 1위! 최대규모! NO.1!"
3. **"휴식·케어의 언어만 쓴다"** — 선정성 연상 어휘는 카테고리 오분류(성인 판정)를 부르고,
   그 순간 AI 개요 노출 자체가 사라진다.

### 3-2. 어휘 사전

| | 권장 | 금지/회피 |
|---|---|---|
| 서비스 성격 | 휴식, 케어, 관리, 이완, 회복, 쉼 | 힐링파트너, 설렘, 은밀한, 특별한 만남 |
| 관리사 | 관리사, 전문 관리사, 검증된 관리사 | 훈남, 조각남, 매니저 초이스, 외모 등급 |
| 고객 | 고객님, 지친 하루를 보낸 당신 | 언니들, 여성분들만 아는 |
| 강조 | 24시간, 연중무휴, 투명한 가격 | 1위, NO.1, 최대규모, 재방문율 1위 |
| 감정 | 위로, 공감, 조용한 휴식, 다독임 | 짜릿한, 황홀한, 잊지 못할 |

### 3-3. 문체 규칙

- 존댓말("~입니다/~하실 수 있습니다") 통일. 반말·구어체("~해요")는 블로그 감성 칼럼에서만 허용.
- 한 문장 60자 이내 목표. 쉼표 3개 이상이면 문장을 쪼갠다.
- 이모지·특수문자·물결표 남용 금지 (♥, ~~, ★). 신뢰 신호를 깎는다.
- 초성어(ㅌㄷㅇ)는 /meaning/ 페이지의 설명 맥락에서만 사용.

### 3-4. 페이지별 톤 다이얼 요약

```
감성 ◄──────────────────────────────► 정보
블로그칼럼(70:30) > 메인(40:60) > guide/area/manager(30:70)
> faq/trust(20:80) > meaning/price(10:90)
```

원칙: **돈과 신뢰를 다루는 페이지일수록 건조하게, 첫 만남 페이지일수록 따뜻하게.**

## 4. AI 개요 인용을 위한 문장 작성 규칙 (전 페이지 공통)

1. **Copula 정의문을 각 페이지 첫 문단에** — "X는 Y입니다" 구조. AI가 생성할 문장을 페이지가 미리 써준다.
2. **H2 직후 1~2문장이 발췌 단위** — 모든 H2 아래 첫 문장은 그 섹션의 완결된 요약이어야 한다.
   "그래서", "또한"으로 시작하는 문장을 H2 직후에 두지 않는다(맥락 의존 문장은 발췌 불가).
3. **숫자·목록·표는 텍스트로** — 가격, 절차, 지역은 HTML 표/목록. 이미지 속 정보는 존재하지 않는 정보다.
4. **한 페이지 = 한 질문** — 페이지마다 응답하는 핵심 질문을 하나로 고정하고 title·H1·첫 문단이 같은 질문에 답하게.
5. **일관된 표현 유지** — "여성전용마사지"를 페이지마다 "여성 전용 마사지", "여전마"로 흔들지 않는다.
   엔티티 표기 일관성이 grounding 신뢰도를 높인다.
6. **구조화 데이터** — 전 페이지 `LocalBusiness`(또는 `HealthAndBeautyBusiness`) + /faq/에 `FAQPage`
   + /price/에 표 마크업. 지역 페이지에 `areaServed` 명시.

## 6. 우선순위 로드맵

| 단계 | 작업 | 이유 |
|---|---|---|
| 1 | 메인 + /price/ + /meaning/ | AI 개요 3대 grounding 수요(정의·가격·의미)를 최소 구성으로 충족 |
| 2 | /guide/ + /faq/ + /trust/ | 질문형 쿼리 대응 + 신뢰 신호 — 니치 전체가 비어 있는 영역 |
| 3 | /area/ 실서비스 지역만 | 지역 조합 쿼리 대응. 품질 규칙(3규칙) 지키며 순차 확장 |

② AI 개요 인용 여부 ③ `{지역}토닥이` 쿼리 순위 ④ 브랜드 쿼리(`토닥이 가격` 등) 점유.
